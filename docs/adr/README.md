# Записи о решениях (ADR)

Короткая выжимка «что верно сейчас» по решениям, которые определяют форму
проекта. История — как к решению пришли, что пробовали и что проверили на
эмуляторе — в [docs/decisions.md](../decisions.md): каждый ADR называет его
разделы. Карта кода — [docs/ARCHITECTURE.md](../ARCHITECTURE.md).

| № | Решение | Статус |
|---|---|---|
| [0001](0001-stack.md) | Android-клиент — Kotlin, Compose и Media3, не Tauri | Принято |
| [0002](0002-audio-engine-abstraction.md) | Воспроизведение — за интерфейсом `AudioEngine` | Принято |
| [0003](0003-license-agplv3.md) | Лицензия AGPLv3, без CLA | Принято |
| [0004](0004-di-framework.md) | Внедрение зависимостей — Hilt | Принято |
| [0005](0005-tag-source-v01.md) | Треки и теги в v0.1 — из `MediaStore` | Принято, до v0.2 |
| [0010](0010-ffi-boundary.md) | Граница Kotlin ↔ Rust — UniFFI на макросах, паника не пересекает | Принято |

Номера 0006–0009 заняты под решения v0.2, которые ещё впереди (CRDT,
журнал, провайдер, теги) — `tasks-v0.2.md`. Новый ADR — следующий номер,
тот же порядок разделов: контекст, решение, последствия. Решение, которое отменяет прежнее, не переписывает старый ADR, а
ставит ему статус «заменено NNNN».
