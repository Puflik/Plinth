# 0003. Лицензия AGPLv3, без CLA

- **Статус:** принято, действует.
- **Подробнее:** `docs/plan/01-overview.md`, раздел 1.6 («Почему AGPLv3, а
  не GPLv3») и 1.7 (политика CLA); `docs/plan/22-legal.md`.

## Контекст

Цель автора: никто не должен суметь форкнуть проект, сделать закрытую
экосистему и продавать её.

- **GPLv3 не закрывает SaaS-лазейку.** GPL срабатывает при распространении
  бинарников. Поднять на коде сетевой сервис и ничего не раздавать — законно,
  исходники открывать не нужно. Для Plinth лазейка реальна: ядро с матчингом
  версий, рекомендациями и агрегацией провайдеров удобно превратить в
  серверный бэкенд.
- **Лицензии с прямым запретом продажи** (PolyForm Noncommercial, Commons
  Clause, BSL) стоят слишком дорого: F-Droid принимает только FOSS,
  NewPipeExtractor (GPL) с ними несовместим — путь к YouTube-провайдеру
  закрывается, контрибьюторов почти не будет, а «некоммерческое» юридически
  размыто.

## Решение

- **GNU AGPLv3** для всего репозитория.
- **Без CLA.** Контрибьютор сохраняет права на свой вклад и отдаёт его под
  AGPLv3.

## Последствия

- Сетевой сервис на коде Plinth обязан открыть исходники так же, как APK.
- Продавать можно, но покупатель получает исходник с правом раздавать
  бесплатно — бизнес-модель закрытого форка умирает в первый день. Компании,
  запрещающие AGPL внутри, проект не возьмут; для этой цели это плюс.
- Выпущенные версии остаются AGPL навсегда. После первого принятого PR без
  CLA перелицензировать код целиком нельзя даже автору — это осознанно:
  цель «чтобы чужие не закрыли», а не «чтобы я мог».
- Зависимости и заимствованный код — только совместимые с AGPLv3 (Apache
  2.0, MIT, GPLv3 — да). Чужой код копируется с его лицензией и копирайтом:
  поэтому, например, скиллы `ecc` (MIT, без текста лицензии) в репозиторий не
  коммитятся.
- Проект можно распространять через F-Droid и GitHub Releases. Google Play не
  входит в каналы распространения.
