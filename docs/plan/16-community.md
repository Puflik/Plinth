# 16. Сообщество и поддержка

Цель автора сформулирована прямо: **«хочу, чтобы этим пользовались»**. Раздел исходит из неё.

## 16.1. Обязательная документация

| Документ | Содержание |
|---|---|
| `README` | Скриншоты · список фич · установка · **сравнение с альтернативами** · дорожная карта |
| `README.ru.md` | Русская версия |
| `CONTRIBUTING.md` | Как собрать · стиль кода · что принимается, а что нет |
| `docs/ARCHITECTURE.md` | Обзор модулей и потоков данных |
| `docs/adr/` | Записи о принятых решениях и почему |
| `CHANGELOG.md` | По формату Keep a Changelog |
| `fastlane/metadata/` | Метаданные и скриншоты для F-Droid |

⚠️ `ARCHITECTURE.md` и ADR — **рабочий инструмент, а не формальность.** При разработке через AI они нужны каждую сессию, чтобы агент не переизобретал уже принятые решения.

## 16.2. Шаблоны issue

`Баг` · `Запрос фичи` · **`Сломался провайдер`** — отдельный шаблон, потому что это будет самый частый тип обращений после выхода YouTube-провайдера. В шаблоне: какой провайдер, что именно не работает, версия приложения, версия конфига экстрактора.

## 16.3. Язык репозитория

**Английский основной** — README, issues, коммиты, код, комментарии. Русский — в отдельном `README.ru.md`.

Обоснование: цель «хочу, чтобы пользовались». Русскоязычный репозиторий отсекает большую часть потенциальной аудитории и почти всех контрибьюторов-переводчиков.

## 16.4. Релизный цикл

**По готовности волны** до v1.0 — редко, но содержательно. После v1.0 — по необходимости плюс **hotfix-релизы при поломке провайдеров**, которые будут регулярными после выхода YouTube.

## 16.5. Промо-материалы

Скриншоты, иконка, баннер для F-Droid, оформление README — **повешено в долг** до первого публичного релиза (ориентир v0.5). См. раздел 26.2.
