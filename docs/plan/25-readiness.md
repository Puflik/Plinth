# 25. Критерии готовности

> ⚠️ **Статус: ориентировочные.** Автор подтвердил порядок по версиям, но критерии требуют детализации и правятся по ходу разработки. Это чек-листы направления, а не контракт.

## v0.1
- [ ] Играет локальный FLAC и MP3
- [ ] Играет при выключенном экране минимум 2 часа без остановки
- [ ] Уведомление и экран блокировки работают с обложкой
- [ ] Звонок ставит на паузу и возвращает после
- [ ] Отключение наушников ставит на паузу
- [ ] Перезапуск восстанавливает позицию
- [ ] Сканирование 5000 треков занимает меньше 30 секунд
- [ ] Ядро воспроизведения работает через абстракцию `AudioEngine`

## v0.5
- [ ] Поиск возвращает результаты из локальной библиотеки и Bandcamp одним списком
- [ ] Онлайн-трек играет и автоматически кэшируется по политике
- [ ] В самолётном режиме кэшированное играет без сбоев
- [ ] Скачанное явно не удаляется автовытеснением
- [ ] Лимит кэша соблюдается и по трекам, и по проценту свободного места
- [ ] Один трек с двумя источниками отображается как один

## v1.0
- [ ] YouTube-провайдер находит и играет произвольный трек
- [ ] Explicit-версия предпочитается при наличии
- [ ] Синхронизированный текст отображается и попадает в такт
- [ ] Рекомендации дают хотя бы один трек в неделю, который автор лайкает
- [ ] Поломка YouTube чинится обновлением конфига, без релиза
- [ ] Автор не открывал YouTube ради музыки месяц

## v1.5
- [ ] Плейлист, созданный на телефоне, появляется на ПК в той же Wi-Fi сети
- [ ] Прослушивание продолжается с той же секунды на другом устройстве
- [ ] Конфликт при одновременном изменении разрешается без потери данных
