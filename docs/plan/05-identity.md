# 5. Алгоритмы идентичности и версий

## 5.1. Определение цензуры — ИИ не нужен

**Вся задача решается детерминированными алгоритмами.** Это принципиальное решение.

| Подзадача | Решение | Тип | Надёжность |
|---|---|---|---|
| Два файла — одна запись? | **Chromaprint / AcoustID** — спектральный отпечаток | Чистый DSP | ~99% |
| Версия помечена explicit? | Флаг `explicit` из iTunes Search API / Deezer / MusicBrainz | Чтение поля | 100%, если источник знает |
| Название говорит о версии? | Словарь маркеров: `Clean`, `Censored`, `Radio Edit`, `Explicit`, `[E]`, `(Album Version)` | Regex + словарь | ~90% |
| Текст зацензурен? | Берём тексты обеих версий из **LRCLIB**, сравниваем построчно. Где в одной мат, а в другой пропуск/замена/`***` → вторая clean | Diff + словарь | ~95% |
| Две версии — одна песня? | Совпадение `artist + title`, близкая длительность, общий **Work** в MusicBrainz | Эвристики + граф | ~85% |

**Почему алгоритмы лучше ИИ здесь:**
- Работают **офлайн**, без сети и без сервера
- **Детерминированы** — один вход всегда даёт один выход, покрывается тестами
- Бесплатны, без лимитов и без ключей на инференс
- Не галлюцинируют

**Где алгоритмы буксуют (5–10% случаев):** кавер против оригинала, ремикс, «то же название — другая песня», live-версии. Лечение — **ручное подтверждение**, а не ИИ.

## 5.2. Chromaprint — технические детали

- Не ИИ и не ML. Детерминированный алгоритм: спектрограмма → компактный хеш, устойчивый к перекодированию и битрейту
- Один трек в FLAC и в MP3 128 даёт совпадающие отпечатки
- Clean и explicit версии дают **разные** отпечатки при **одинаковой** длительности — это почти безошибочная сигнатура пары «оригинал/цензура»
- ⚠️ **Заноза:** оригинал — нативная C-библиотека. Решается Rust-портом `rusty-chromaprint`

**Критически важное, что подтвердилось:**

| Компонент API | Что даёт |
|---|---|
| `Fingerprinter` + `Configuration` | Расчёт отпечатка, пресеты конфигурации (нужен `preset_test2` — тот же, что использует AcoustID) |
| **`FingerprintCompressor`** | **Сжатие отпечатка в формат AcoustID.** Без него была бы доступна только локальная сверка, но не запросы к базе AcoustID → MBID. Это был главный риск, и он снят |
| `match_fingerprints` + `Segment` | Локальное сравнение двух отпечатков с оценкой схожести и общими сегментами — ровно то, что нужно для склейки версий |
| Бинарь `fpcalc` | Порт эталонной CLI, есть с октября 2024 |
| Пример `compare` | **Использует Symphonia** — то есть связка с нашим декодером уже проверена автором крейта |

**Что остаётся сделать перед v0.3:**

1. ⚠️ **Брать зависимость из git, а не с crates.io.** Релиз `0.3.0` от октября 2024 не содержит фиксов 2026 года. Либо git-зависимость с фиксацией коммита, либо попросить автора выпустить релиз
2. ⚠️ **README честно говорит «in-progress port».** Есть коммит «improve compatibility with the reference implementation» — значит совместимость допиливалась. **Обязательна сверка отпечатков с эталонным `fpcalc` на корпусе из 50–100 реальных файлов** разных форматов и битрейтов
3. Проверить сборку под `armeabi-v7a` — 32-битная арифметика во FFT иногда преподносит сюрпризы

**Вывод: риск №2 снижен с «средний» до «низкий».** Запасной путь (C-библиотека через NDK) остаётся, но вероятность его применения мала.
- AcoustID API — бесплатный, требует ключ приложения, rate-limited; отдаёт связку отпечаток → MBID

## 5.3. Матчинг между провайдерами

Грязная задача: `Creep` vs `Creep (Remastered)` vs `creep [official video]` vs `Radiohead - Creep (Lyrics)`.

Порядок применения:
1. Нормализация строки: регистр, знаки препинания, скобочные суффиксы (`official video`, `lyrics`, `HQ`, `audio`), транслитерация
2. Сравнение длительности (±3 с)
3. Если есть аудио — отпечаток
4. Проверка по MusicBrainz Work
5. Порог уверенности → выше порога склеиваем автоматически, ниже → в очередь

Порог настраивается в продвинутом режиме (решение №14).

## 5.4. Локальный аудио-анализ

Rust-ядро через Symphonia считает по каждому треку:
- BPM (темп)
- Энергия (RMS)
- Спектральный центроид («яркость» звучания)
- Тональность / гармонический профиль
- Динамический диапазон

**Зачем:** даёт «похожее по звучанию» **полностью офлайн и без чужих баз**. Чего нет ни у одного локального плеера и что невозможно отключить никаким изменением чужого API.
