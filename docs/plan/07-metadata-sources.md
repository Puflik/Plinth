# 7. Источники метаданных

Отдельная подсистема **обогащения**: очередь задач с кэшем, rate-limiting, ретраями и постоянным локальным хранением результатов. Раз получили — храним навсегда.

| Что нужно | Откуда | Ключ? | Комментарий |
|---|---|---|---|
| **Синхронизированный текст** | **LRCLIB** | Нет | Открытый проект специально для этого. Формат LRC, построчная и пословная синхронизация. Основа для всех open-source плееров |
| Текст без синхронизации | LRCLIB, Genius | Нет / скрейп | Genius — серая зона по ToS |
| **Обложки высокого разрешения** | Cover Art Archive, iTunes Search API, Deezer | Нет | iTunes отдаёт до 3000×3000 без ключа. Превью YouTube — мусор: не квадратные и мыльные |
| **Инфо об артисте** (как в Яндексе) | MusicBrainz + Wikidata/Wikipedia + Last.fm | Last.fm — бесплатный | Биография, годы активности, состав группы, жанры |
| **Кредиты** (кто написал, спродюсировал, играл) | MusicBrainz, Discogs | Discogs — токен | Именно это делает инфу глубокой |
| Дискография, связи артистов | MusicBrainz | Нет | Граф «участвовал в», «похож на», «сайд-проект» |
| Теги и жанры | Last.fm, MusicBrainz | Частично | Народные теги — топливо для рекомендаций |
| Флаг explicit | iTunes Search API, Deezer, MusicBrainz | Нет | Основа политики версий |
| Ссылки на другие сервисы | Odesli / song.link | Нет | Маршрутизатор между площадками |
| Canvas (видео-луп как в Spotify) | — | — | Источника нет. Замена: анимация из обложки |

⚠️ **Rate limits, которые надо заложить в архитектуру:**
- **MusicBrainz — 1 запрос в секунду** для анонимов, обязателен осмысленный User-Agent
- AcoustID — лимитирован
- Last.fm — лимитирован

Отсюда требование: обогащение — **асинхронная очередь с приоритетами**, а не синхронные вызовы при открытии экрана.
