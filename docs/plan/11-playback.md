# 11. Требования к воспроизведению

Базовые, обязательные с v0.1:

| Требование | Обоснование |
|---|---|
| **Работа при выключенном экране** | Исходная боль автора №1 |
| Foreground service + MediaSession | Без этого Android убьёт процесс |
| Уведомление с кнопками, экран блокировки с обложкой | Базовое ожидание |
| Audio focus: пауза на звонке, ducking на уведомлении | Иначе приложение считается сломанным |
| Кнопки гарнитуры | Базовое ожидание |
| Автопауза при отключении наушников | Иначе музыка заорёт из динамика |
| Resume позиции после перезапуска | Базовое ожидание |
| Gapless | Критично для концептуальных альбомов и live |
| Устойчивость к вендорским «убийцам процессов» (Xiaomi, Samsung, Huawei) | Отдельная задача с инструкцией для пользователя |

Форматы v0.1 (через Media3): MP3, AAC, FLAC, ALAC, OGG, Opus, WAV.
Форматы v2+ (через Rust-движок): DSD, APE, WavPack.

## 11.1. Модель очереди

Главный источник путаницы во всех плеерах: **слушаешь плейлист, заходишь в альбом, жмёшь на третий трек — что происходит?**

Рассматривались четыре модели: *замена* (очередь стирается — так делает большинство локальных плееров), *контексты* (Spotify), *стек* (альбом играет поверх, потом возврат в плейлист), *спросить* (Poweramp).

**Принятое решение: они не взаимоисключающие, берём три из четырёх одновременно.**

| Механизм | Как работает | Где живёт |
|---|---|---|
| **База — контексты** | Очередь = контекст (альбом / плейлист / радио) **плюс** вручную добавленное. Новый контекст заменяет старый, но **вручную добавленное выживает** | Всегда |
| **Выбор по долгому нажатию** | Тап = играть в контексте. Долгое нажатие = меню: `играть следующим` / `в конец очереди` / `заменить очередь` | Всегда |
| **Стек** | «Возвращаться в предыдущий контекст после окончания» | Настройка, выключена по умолчанию, продвинутый режим |

## 11.2. Поведение очереди — детали

| Вопрос | Решение | Обоснование |
|---|---|---|
| **Shuffle** перемешивает очередь или порядок обхода? | **Порядок обхода.** Сама очередь остаётся на месте | Выключил shuffle — вернулся к нормальному порядку, не потеряв позицию. Строго лучше, минусов нет |
| Очередь переживает перезапуск приложения? | **Да** | Базовое ожидание |
| Что играет после конца очереди? | **Похожее** (решение №19) | Настраивается: тишина / похожее / радио |
| Очередь синхронизируется между устройствами? | Да — в рамках «продолжить на другом устройстве» (v1.5) | |
| Редактирование очереди | Drag & drop, свайп для удаления, превью следующего трека | |
