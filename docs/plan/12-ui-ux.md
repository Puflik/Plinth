# 12. Интерфейс и UX

## 12.1. Режимы

Переключатель `Простой ⇄ Продвинутый` в настройках. Архитектурно — всегда полный набор точек переопределения, простой режим их прячет. См. 2.6.

## 12.2. Объяснимость

Каждое автоматическое решение раскрывается по тапу в обоих режимах. Это не настройка, а прозрачность. Прямое следствие исходной претензии автора к Яндексу и Spotify: «сервис решил за меня».

## 12.3. Единый каталог

Пользователь видит **один список треков**, а не разделение по источникам. Источник — атрибут трека, видимый по запросу, а не способ навигации.

## 12.4. Онбординг — модель B+

Рассматривались три модели: *ноль вопросов* (сразу библиотека), *мастер настройки* (5–7 экранов до первого звука), *минимум сразу, остальное в контексте*.

**Принято: B+ — мастер, который можно пропустить на любом шаге.**

```
Шаг 1  Разрешение на файлы            [обязательный технически]
Шаг 2  Выбор папок                    [Пропустить]
Шаг 3  Память или SD                  [Пропустить]
Шаг 4  Импорт вкуса                   [Пропустить]
Шаг 5  Провайдеры                     [Пропустить]
Шаг 6  Качество и трафик              [Пропустить]
Шаг 7  Простой или продвинутый режим   [Пропустить]
                                      [Пропустить всё]
```

**Обоснование выбора B+ вместо «минимума».** Аргумент «7 экранов отпугнут половину» взят из мира App Store, где приложения ставят импульсивно. Здесь аудитория другая: человек нашёл репозиторий, скачал APK с GitHub, разрешил установку из неизвестных источников и запустил. Это мотивированный технический пользователь — такие не терпят настройку, а **любят** её. Мастер для них не барьер, а признак серьёзного инструмента.

**Пропущенные шаги возвращаются контекстно**, в момент, когда становятся нужны:

| Триггер | Предложение |
|---|---|
| Кэш впервые приближается к лимиту, на SD есть место | «Нашёл 3000 треков на SD — перенести кэш туда?» |
| Рекомендациям нечего предложить | «Подтянуть твой вкус из Last.fm?» |
| Поиск не нашёл трек в локальной библиотеке | «Поискать в онлайн-источниках?» |
| Человек второй раз лезет в одну и ту же настройку | «Включить продвинутый режим?» |

⚠️ **Мастер растёт вместе с версиями.** В `v0.1` в нём реально два шага (разрешение + папки), потому что настраивать больше нечего. К `v1.0` он дорастает до семи.

**Обязательное разрешение:** `READ_MEDIA_AUDIO` (Android 13+), на более старых — `READ_EXTERNAL_STORAGE`.

## 12.5. Пустое состояние

Сценарий: у человека нет ни одного локального аудиофайла. До v0.2 онлайн-источников нет вообще. Пустой экран — худшее первое впечатление.

**Принято: проводник + «что дальше».**

| Элемент | Содержание |
|---|---|
| **Проводник** | Сразу предлагаем выбрать папку вручную, с просмотром файловой системы — не просто «файлы не найдены» |
| **«Что дальше»** | Честная дорожная карта: «онлайн-поиск появится в версии 0.2», со ссылкой на релизы |

Отброшено: демо-контент из public domain (требовал бы онлайна уже в v0.1). Проблема решена иначе — переносом Internet Archive в v0.2.

## 12.6. Стартовый экран — адаптивный

Рассматривались четыре модели: *библиотека в центре* (Poweramp, foobar2000), *лента открытий в центре* (Spotify, Яндекс), *продолжить с того же места* (Plexamp), *адаптивный*.

**Принято: адаптивный, с возможностью зафиксировать вручную.**

Настройка `Стартовый экран: Авто / Библиотека / Открытия / Продолжить` — доступна в обоих режимах, умолчание **Авто**.

**Правила режима «Авто»** — срабатывает первое подходящее сверху вниз:

| Условие | Куда попадаешь |
|---|---|
| Библиотека пуста | Пустое состояние: проводник + «что дальше» |
| Играло меньше 30 минут назад | **Продолжить** — та же очередь, та же позиция |
| Перерыв 30 минут – 12 часов | **Библиотека**, сверху «недавнее» |
| Перерыв больше 3 дней | **Открытия** — забытое + новое |
| Есть непрослушанный релиз артиста, на которого подписан | **Открытия** с этим релизом сверху |
| Утро буднего дня, есть утренний срез профиля вкуса | **Продолжить** с утренним миксом |

⚠️ **До v0.9 «Авто» работает наполовину** — вкладки «Открытия» ещё не существует, правила с ней не срабатывают. Настройка появляется в `v0.1`, полноценной становится в `v0.9`.

По сквозному принципу объяснимости решение раскрывается: *«Показываю продолжение: ты слушал 20 минут назад»* — со ссылкой на настройку.

## 12.8. Как гибридность выражается в интерфейсе

Единственная часть UI без аналогов — списывать не с чего. У трека может быть три версии и пять источников, и надо решить, сколько из этого человек видит.

**Принято: B в простом режиме, C в продвинутом.**

| Режим | Что видно в строке трека |
|---|---|
| **Простой (B)** | Один индикатор состояния: ● скачан · ◐ в кэше · ○ только онлайн · ⊘ недоступен |
| **Продвинутый (C)** | Иконка провайдера + битрейт + метка версии (`clean`, `live`, `remaster`) прямо в строке. Плюс **ручной выбор устройства вывода** |

Отброшен вариант A (источник не показан нигде) — человек не понимает, что будет играть оффлайн, а что нет.

## 12.10. Слои интерфейса плеера

Полный перечень желаемых элементов полноэкранного плеера — около 45 позиций. На одном экране они нечитаемы. Принята шестиуровневая раскладка по глубине взаимодействия.

| Глубина | Как достать | Что там |
|---|---|---|
| **D0** Мини-плеер | Всегда поверх навигации | Мелкая обложка · название и артист · play/pause · тонкая полоска прогресса |
| **D1** Плеер: ядро | Свайп вверх по мини-плееру | Большая обложка · название · артист (кликабелен) · бейдж версии, если не Original · прогресс и время (тап — прошло ⇄ осталось) · prev/play/next · shuffle и repeat · лайк · меню ⋮ · иконка устройства вывода |
| **D2** Панели | Свайп по обложке + точки-табы под ней | **Текст** (караоке с пословной подсветкой, перевод, подгонка тайминга) · **Очередь** (drag & drop, превью следующего) · **Похожие** («почему это играет») · **Инфо** (формат, битрейт, источник, ReplayGain, счётчик прослушиваний, дата добавления, теги) |
| **D3** Меню ⋮ | Одно нажатие | В плейлист · в очередь следующим · к альбому · к артисту · скачать · найти лучшее качество · открыть в источнике · **купить / поддержать артиста** · поделиться карточкой · таймер сна · не рекомендовать · заблокировать артиста · оценка звёздами |
| **D4** Экран трека | Из меню или тапа по названию | См. 12.9 |
| **D5** Настройки | Вкладка | Всё остальное |

**Модификатор «продвинутый режим»** — не отдельный слой, а добавка в существующие:

| Куда | Что добавляется |
|---|---|
| D1 | Waveform вместо обычной полоски прогресса · формат и битрейт прямо под названием |
| D2 | Новая панель **«Звук»**: эквалайзер, баланс каналов, питч отдельно от скорости, crossfade, A-B повтор фрагмента |
| D3 | Редактор тегов · ручной выбор устройства вывода |
| D4 | Отпечаток, MBID, лог решений политики |

### Полный перечень элементов по группам

**Информация о треке:** счётчик прослушиваний · дата добавления в библиотеку · теги и жанры · бейдж версии (explicit/clean/live/remaster) · формат и битрейт в реальном времени · индикатор ReplayGain · индикатор буферизации и сети · превью следующего трека · таймлайн сессии («что играло до») · переключение «прошло ⇄ осталось»

**Действия с треком:** оценка звёздами · добавить в плейлист · добавить в очередь следующим · перейти к альбому · перейти к артисту · редактировать теги · открыть в источнике · **купить / поддержать артиста** · найти лучшее качество · плашка «доступен в lossless»

**Управление звуком:** громкость внутри приложения · баланс каналов и моно · питч отдельно от скорости · **A-B повтор фрагмента** (для разучивания музыки) · выбор устройства вывода · быстрое включение crossfade

**Открытия и вкус:** не рекомендовать этот трек · заблокировать артиста · «почему это играет»

**Текст:** караоке-режим с пословной подсветкой · перевод · подгонка тайминга на лету

**Визуальное:** анимированная обложка · цвет интерфейса из обложки · waveform вместо полоски · визуализатор

**Социальное:** красивая карточка для шеринга (обложка + строчка текста)

## 12.11. Жесты — настраиваемые

По образцу AIMP для Android: каждый жест настраивается, умолчания следуют доминирующей конвенции.

| Жест | Умолчание | Альтернативы в настройках |
|---|---|---|
| Свайп по обложке влево/вправо | **Смена трека** | Переключение панелей · ничего |
| Свайп вверх | **Очередь** | Текст · похожие · ничего |
| Свайп вниз | **Свернуть в мини-плеер** | Ничего |
| **Тап по обложке** | **Переключение текст ⇄ обложка** | Пауза · следующая панель · ничего |
| Двойной тап по половине экрана | **±10 секунд** | Лайк · ничего |
| Долгое удержание next/prev | **Быстрая перемотка** | Следующий альбом · ничего |
| Свайп по мини-плееру влево/вправо | **Смена трека** | Ничего |

**Разрешение конфликта жестов.** Свайп влево-вправо традиционно означает смену трека, но панели тоже просятся на горизонтальный свайп. Рассматривались три варианта: (A) свайп = панели, смена трека только кнопками; (B) свайп = трек, панели табами; (C) свайп = трек, панели вертикальным свайпом.

Принято: **умолчание B** — свайп по обложке меняет трек, панели переключаются **точками-табами под обложкой**. Табы сразу показывают, что панели есть и сколько их. Смена трека кнопками — то, чем люди пользуются в 95% случаев, остаётся на привычном жесте. Вариант A доступен через настройку.

## 12.13. Состав слоя D1

В D1 помещается 6–8 интерактивных зон, дальше экран визуально рассыпается. Часть элементов сделана **условными** — они занимают место только когда актуальны.

```
┌──────────────────────────────────────┐
│  ▼                    🎧    ⋮        │  свернуть · вывод (условно) · меню
│                                      │
│         [   ОБЛОЖКА   ]              │
│                                      │
│           ● ○ ○ ○                    │  точки-табы панелей D2
│                                      │
│  Creep                          ♡    │  название · лайк
│  Radiohead            [explicit]     │  артист (кликабелен) · бейдж (условно)
│                                      │
│  ─────●────────────────              │
│  1:24                    4:18        │  тап переключает прошло ⇄ осталось
│                                      │
│    ⤨     ⏮    ▶    ⏭     ⟳          │  shuffle · prev · play · next · repeat
└──────────────────────────────────────┘
```

**Условные элементы:** иконка устройства вывода (только если вывод не телефон) · бейдж версии (только если версия не Original) · индикатор буферизации (только при стриме) · плашка «доступен в lossless» (только при наличии лучшего источника).

**Добавляется в продвинутом режиме:** waveform вместо полоски прогресса · строка `FLAC 1411 kbps · локальный файл` под именем артиста.

### Текст

| Элемент | Вердикт | Обоснование |
|---|---|---|
| Караоке с пословной подсветкой | Оставить, D2 | Пословная синхронизация есть в LRCLIB не у всех треков — **обязателен каскад фоллбэков**: пословная → построчная → статичный текст → нет текста |
