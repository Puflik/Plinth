## 23.3. Режим работы с AI

Цели «пользоваться каждый день» и «научиться и разобраться» тянут в разные стороны при полной генерации кода агентами. Предлагаемое разрешение:

| Пишет AI | Пишет автор |
|---|---|
| Бойлерплейт, UI-разметка, тесты | **Ядро плеера** |
| Обвязка провайдеров по готовому интерфейсу | **Модель данных** |
| Миграции, CI, скрипты | **Алгоритмы матчинга и ранжирования** |
| Разбор чужих API | **Всё, что хочется понять** |

**Следствие для архитектуры:** мелкие независимые модули с чёткими контрактами. Агент отлично делает «один модуль по интерфейсу» и плохо — «проект целиком».
