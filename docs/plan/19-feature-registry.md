# 19. Полный реестр фич

142 пункта. Группы A–H собраны из Spotify, Яндекс Музыки, YouTube Music, Apple Music, Poweramp, foobar2000, Plexamp, VLC, Navidrome и NewPipe-семейства. Группа I добавлена отдельно — это фичи, которых нет в чужих плеерах, потому что те живут в сторе и не агрегируют чужие источники.

**Решение автора: нужны все, кроме явно отклонённых.** Приоритизация выражена не отбрасыванием, а порядком волн (раздел 20).
