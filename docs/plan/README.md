## Как читать

- Разделы 1–2 — зачем и что. 3–17 — как. 18–21 — что и в каком порядке делать.
  22–27 — риски, ограничения, незакрытые вопросы.
- Для поиска по плану дешевле `graphify query "<вопрос>"`, чем чтение файлов.
- Правки вносятся в файлы глав; `plan.md` — только точка входа и оглавление.
