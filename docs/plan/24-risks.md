# 24. Риски проекта

| № | Риск | Вероятность | Последствия | Митигация |
|---|---|---|---|---|
| 1 | **Угасание мотивации** на длинной дистанции (10–16 мес до v1.0) | **Высокая** | Проект умирает | Волны дают работающий результат каждые 1–3 месяца. v0.1 уже играет музыку |
| 2 | `rusty-chromaprint` окажется незрелым | ~~Средняя~~ → **Низкая** ✅ | Ломается v0.3 | **Проверен 2026-09-21** (раздел 5.2): MIT, репозиторий живой, есть `FingerprintCompressor` для AcoustID. Остаётся сверка отпечатков с эталонным `fpcalc` и брать зависимость из git |
| 3 | Rust окажется тяжелее ожиданий | Средняя | +2–3 месяца | Начать с v0.1 на чистом Kotlin, ядро вводить в v0.2 постепенно |
| 4 | YouTube-экстрактор ломается чаще, чем есть силы чинить | **Высокая** | Главная фича деградирует | Удалённый конфиг (6.3). Многопровайдерность — YouTube не единственный |
| 5 | Матчинг версий даёт много ложных склеек | Средняя | Испорченная библиотека, потеря доверия | Обратимость склейки. Высокий порог автоматики. Очередь ручного разбора |
| 6 | P2P не встаёт через CGNAT | Средняя | Синк не работает у части людей | LAN-прямое как основной путь. Честное сообщение об ошибке |
| 7 | Оценка времени занижена в 1,5–2 раза | **Высокая** (так бывает почти всегда) | Сроки уезжают | Волны независимы, можно остановиться на любой |
| 8 | Вендорские «убийцы процессов» ломают фон | Средняя | Возврат к исходной боли | Отдельная задача + инструкция пользователю |
| 9 | Rate limits MusicBrainz душат обогащение | Низкая | Медленное наполнение метаданных | Асинхронная очередь с приоритетами, агрессивный локальный кэш |
| 10 | Правовые претензии | Низкая для pet-проекта | Требование удалить репозиторий | Раздел 17. Архитектура изолирует рискованные провайдеры |

**Самое рискованное допущение проекта:** что автор выдержит 10–16 месяцев по 2 часа в день до момента, когда приложение станет полноценной заменой YouTube.
