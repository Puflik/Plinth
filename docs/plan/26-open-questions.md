## 26.3. Закрытые 2026-09-21 — второй проход

| Вопрос | Решение |
|---|---|
| **Зрелость `rusty-chromaprint`** | ✅ **Проверен практически.** MIT, репозиторий живой (коммиты март 2026), `FingerprintCompressor` для AcoustID есть, пример на Symphonia от автора. Риск №2 снижен до низкого. Подробности в 5.2 |
| **Сигналы для профиля вкуса** | Собираем всё, **кроме поисковых запросов**. Время суток и тип вывода дают наибольший прирост качества, а данные не покидают устройство. Переключатель «расширенные сигналы» в настройках приватности, включён по умолчанию |
| **API-ключи в открытом репозитории** | Last.fm и AcoustID — ключ подставляется из GitHub Secrets в сборке `github`. В сборке `fdroid` ключа нет → экран «введи свой ключ» с инструкцией. Discogs — только пользовательский |
| **YouTube раньше или позже** | Остаётся в **v1.0**. Ранняя вставка срастит абстракцию провайдера с особенностями YouTube |
| **Лайк или звёзды** | **Только лайк.** Две системы оценки ломают движок рекомендаций и нагружают пользователя. Фича 42 (звёзды) отклонена; при необходимости градаций — «супер-лайк» |
| **Язык репозитория** | **Английский основной**, `README.ru.md` отдельно |
| **Релизный цикл** | По готовности волны до v1.0; после — по необходимости плюс hotfix при поломке провайдеров |
| **Политика CLA** | **Без CLA.** CLA даёт право закрыть код автору, но отпугивает контрибьюторов. Цель «чтобы чужие не закрыли» достигается и без него, а отсутствие CLA делает проект необратимо открытым |
| **Discord Rich Presence (137)** | **Берём**, v2+. Дёшево и работает на распространение |
| **Chromecast / DLNA (138)** | **В долг** — не отклонено, но и не запланировано. Нужен свой медиарендерер, это недели работы |
| **UI экрана спорных склеек** | Формат зафиксирован: карточка с двумя треками рядом, кнопки `одно и то же` / `разное` / `пропустить`, управление свайпом. Раскладка — на стадии макетов |
| **Умолчания раздела 18** | Оставлены как есть, пересмотр после месяца реального использования v0.5 |
| **Решения вне таблицы 18** | Список признан полным |
