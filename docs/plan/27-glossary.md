# 27. Глоссарий

| Термин | Значение |
|---|---|
| **Track** | Логическая песня. Носитель лайков и статистики |
| **Version** | Конкретная запись песни: original / clean / remaster / live / acoustic |
| **Source** | Конкретный способ получить байты: файл, поток, ID у провайдера |
| **Провайдер** | Модуль-источник контента с единым интерфейсом |
| **MBID** | MusicBrainz Identifier — глобальный канонический идентификатор |
| **Chromaprint / AcoustID** | Акустический отпечаток аудио и база сопоставления с MBID |
| **LRCLIB** | Открытая база синхронизированных текстов песен |
| **ListenBrainz** | Открытая альтернатива Last.fm от MetaBrainz; источник коллаборативных рекомендаций |
| **CRDT** | Структура данных, сливающаяся без конфликтов; основа синхронизации |
| **UniFFI** | Генератор биндингов Rust → Kotlin/Swift от Mozilla |
| **Symphonia** | Библиотека декодирования аудио на чистом Rust |
| **Media3 / ExoPlayer** | Медиастек Google для Android |
| **Audio offload** | Режим, где декодирование уходит в аппаратный DSP; экономит батарею |
| **R2 / R3** | Две границы использования Rust: ядро без звука (R2) и ядро со звуком (R3) |
| **Слой открытий / слой любимого** | Разделение источников на «много и лоси» и «мало и lossless» |
| **Апгрейд трека** | Автоматическая замена источника на более качественный с сохранением статистики |
