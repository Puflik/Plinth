## Батарея (H4): меньше 2 % в час в фоне

Эмулятор батарею не тратит — только телефон.

1. Заряд 80–100 %, **не на зарядке**, Wi-Fi и связь как обычно, громкость
   тихая, наушники или динамик.
2. `adb shell dumpsys batterystats --reset`, запомнить уровень:
   `adb shell dumpsys battery | grep level`.
3. Очередь с повтором, экран выключен, **2 часа** — удобно совместить с
   пунктом 2 (`background_check.py --minutes 120 --no-doze`).
4. Снова уровень. Норма — падение не больше **4 %** за 2 часа.
5. Если больше — кто тратит: `adb shell dumpsys batterystats` → раздел
   «Estimated power use», строка uid приложения (uid —
   `adb shell pm list packages -U io.github.puflik.plinth`).

## Автоматическое

- Обычный прогон: `./gradlew ktlintCheck detekt testGithubDebugUnitTest
  testFdroidDebugUnitTest connectedGithubDebugAndroidTest`.
- Скан 5 000 треков (только по запросу, файлы создаются минут 10):
  `./gradlew connectedGithubDebugAndroidTest -Pacceptance
  -Pandroid.testInstrumentationRunnerArguments.class=io.github.puflik.plinth.acceptance.ScanPerformanceTest`;
  время — в logcat с тегом `PlinthAcceptance`.
- Фон: `python tools/background_check.py --minutes 10` (эмулятор, с Doze).
- `connectedAndroidTest` удаляет приложение: после — `adb install -r` и
  `adb shell pm grant <пакет> android.permission.READ_MEDIA_AUDIO`,
  `… POST_NOTIFICATIONS`.
