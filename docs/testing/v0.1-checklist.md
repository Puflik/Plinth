# Приёмка v0.1 «Звук»: чек-лист

Пункты раздела 25 плана («Критерии готовности») плюс то, что добавили эпики
B–G. Автоматическое проверяется тестами и скриптами; остальное — руками,
**на живом телефоне**, лучше на нескольких (Xiaomi или Samsung — там убийцы
фона злее всего). Итог прогона — в `docs/decisions.md`, раздел эпика H.

Колонка «Эмулятор» — прогоны 2026-09-24/25: **36** — `Medium_Phone_API_36.0`
(Android 16), **30** — `Plinth_API_30` (Android 11), **26** — `Plinth_API_26`
(Android 8.0), отладочная сборка. Без номера — только API 36. Находки Н1–Н8 и
как их воспроизвести — `docs/decisions.md`, раздел «v0.1 на Android 8 и 11»;
логи и снимки — `docs/testing/v0.1-old-android/`.
Колонка «Телефон» — для автора: модель, Android, ✅ / ❌ и что видно.
Прогон 2026-09-25: TECNO CAMON 30 (`CL6`), Android 16, HiOS 16.3, релиз 0.1.1
из GitHub Release, adb по Wi-Fi; музыка — на SD-карте. Находки Т1–Т2 и
подробности — `docs/decisions.md`, раздел «v0.1.1 на телефоне».

## Батарея (H4): меньше 2 % в час в фоне

Эмулятор батарею не тратит — только телефон.

1. Заряд 80–100 %, **не на зарядке**, Wi-Fi и связь как обычно, громкость
   тихая, наушники или динамик.
2. `adb shell dumpsys batterystats --reset`, запомнить уровень:
   `adb shell dumpsys battery | grep level`.
3. Очередь с повтором, экран выключен, **2 часа** — удобно совместить с
   пунктом 2 (`background_check.py --minutes 120 --no-doze`).
4. Снова уровень. Норма — падение не больше **4 %** за 2 часа.
5. Если больше — кто тратит: `adb shell dumpsys batterystats` → раздел
   «Estimated power use», строка uid приложения (uid —
   `adb shell pm list packages -U io.github.puflik.plinth`).

**Телефон (TECNO CAMON 30, Android 16):** ❌ формально — 97 → 92 % за 2 ч
(5 %), динамик на тихой громкости, VPN. По `batterystats` у Plinth
87,8 мА·ч, но 68,6 из них — `audio` (модель питания звукового тракта);
собственные CPU и wakelock — ~19 мА·ч за 2 ч (0,2 %/ч). Для сравнения нужен
тот же прогон с другим плеером.

## Автоматическое

- Обычный прогон: `./gradlew ktlintCheck detekt testGithubDebugUnitTest
  testFdroidDebugUnitTest connectedGithubDebugAndroidTest`.
- Скан 5 000 треков (только по запросу, файлы создаются минут 10):
  `./gradlew connectedGithubDebugAndroidTest -Pacceptance
  -Pandroid.testInstrumentationRunnerArguments.class=io.github.puflik.plinth.acceptance.ScanPerformanceTest`;
  время — в logcat с тегом `PlinthAcceptance`.
- Фон: `python tools/background_check.py --minutes 10` (эмулятор, с Doze).
- `connectedAndroidTest` удаляет приложение: после — `adb install -r` и
  `adb shell pm grant <пакет> android.permission.READ_MEDIA_AUDIO`,
  `… POST_NOTIFICATIONS`.
