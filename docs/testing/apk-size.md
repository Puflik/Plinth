# Размер APK по ABI (F4)

Замер 2026-09-28, ветка `provider` (`eec33cb` + правки F), релиз `github`:
R8 и сжатие ресурсов включены, Rust — профиль `release` (`opt-level = "z"`,
LTO, `strip`). Подписи в ворктри нет, APK неподписанный: блок подписи добавит
единицы килобайт. Как собрать и посчитать — в конце.

## Итог

| | v0.1.0 | v0.2, шаг 1 (A2.4) | **v0.2 (F)** |
|---|---|---|---|
| APK, все четыре ABI | 2,9 МБ | 4,9 МБ | **16,3 МБ** |
| `libplinth_ffi.so`, четыре ABI | — | 1,36 МБ | **12,58 МБ** |
| остальное (dex, ресурсы, манифест), сжато | 2,9 МБ | ≈ 3 МБ | 2,96 МБ, из них dex 2,50 МБ |

Бюджет из `docs/BUILD.md` — 30 МБ: занято 54 %. Весь прирост — ядро:
на шаге 1 оно было пустым соединением (250–380 КБ на ABI), теперь в нём
SQLite (`rusqlite`, собранный из исходников), журнал на `yrs`, чтение тегов,
провайдеры с `serde_json` (E3a: +0,21 МБ на ABI).

## По ABI

`.so` лежат в APK несжатыми (так их грузят прямо из APK), поэтому APK
устройства хранит все четыре набора, а работают библиотеки одной ABI.

| ABI | `libplinth_ffi.so` | все `.so` ABI | сжатые deflate | APK только этой ABI, оценка |
|---|---|---|---|---|
| arm64-v8a | 3,11 МБ | 3,29 МБ | 1,70 МБ | 6,25 МБ |
| armeabi-v7a | 2,53 МБ | 2,66 МБ | 1,53 МБ | 5,62 МБ |
| x86 | 3,53 МБ | 3,66 МБ | 1,81 МБ | 6,62 МБ |
| x86_64 | 3,41 МБ | 3,55 МБ | 1,71 МБ | 6,51 МБ |

«Все `.so` ABI» — ядро, `libjnidispatch.so` (JNA, 116–166 КБ) и две
библиотеки AndroidX (`graphics.path`, `datastore_shared_counter`, по
6–11 КБ). «APK только этой ABI» — несжатые `.so` этой ABI плюс всё
остальное сжатым, без накладных расходов zip.

## Проверено

- `.so` каждой ABI — своей архитектуры (`llvm-readelf -h`): AArch64, ARM
  (ELF32), x86-64, Intel 80386 (ELF32);
- 64-битные сегменты `LOAD` выровнены по 16 КБ (`0x4000`, Android 15+),
  32-битные — по 4 КБ, как и положено; `zipalign -c -P 16 -v 4` —
  «Verification successful»;
- запуском — x86_64 (эмуляторы) и arm64-v8a (телефон, раньше: DoD эпика A,
  C4, D4d). x86 и armeabi-v7a не запускались: образов x86 нет, armeabi-v7a
  на x86_64-компьютере не запустить (ответ автора F).

## Если размер станет мешать

Решение за автором, в v0.2 ничего не меняется:

- **APK по ABI** (`splits.abi`) — 5,6–6,6 МБ вместо 16,3 МБ, но четыре
  файла в релизе GitHub и выбор ABI человеком; F-Droid собирает сам;
- **сжатые `.so`** (`packaging.jniLibs.useLegacyPackaging = true`) — `lib/`
  с 13,2 до ≈ 6,8 МБ, APK ≈ 9,9 МБ; при установке Android распакует `.so`
  своей ABI (+3,3 МБ на устройстве);
- **сам код ядра** — `cargo bloat` по крейтам: что из `rusqlite`, `yrs` и
  чтения тегов реально нужно.

## Как повторить

```bash
./gradlew :app:assembleGithubRelease
unzip -lv app/build/outputs/apk/github/release/app-github-release-unsigned.apk | grep "lib/"
```

Выравнивание — `llvm-readelf -lh` из NDK по `app/build/rust/jniLibs/<abi>/`
и `zipalign -c -P 16 -v 4` из build-tools по APK.
