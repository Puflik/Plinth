# Тестовый APK с YouTube

В CI artifact прикрепляется к успешному запуску GitHub Actions: `plinth-github-debug-<SHA>`. Он содержит snapshot flavor `github`, включая провайдер YouTube. Это debug-сборка с отдельным package ID от release, поэтому она может устанавливаться рядом с релизной версией.

Версия внутри приложения может отображаться как `0.2.3-debug`: это текущая версия приложения, а не номер snapshot-кода из ветки.

Чтобы получить APK:

1. Войдите в GitHub и откройте последний успешный запуск в [списке сборок `main`](https://github.com/Puflik/Plinth/actions/workflows/ci.yml?query=branch%3Amain+is%3Asuccess).
2. В разделе Artifacts скачайте `plinth-github-debug-<SHA>.zip`.
3. Распакуйте архив; внутри будет APK для ручной установки при желании.

Загрузка APK сама по себе не устанавливает приложение и не меняет существующие данные. Установка на телефон и проверка живого YouTube выполняются отдельно вручную.


## Установка на телефон

Для Android 8 и новее можно [скачать ZIP с APK `a4a0911`](https://github.com/Puflik/Plinth/actions/runs/45589418484/artifacts/15009987827). Ссылка проверена 28 ноября 2026 года. GitHub хранит этот архив до 2 декабря, 14:55 по Екатеринбургу. После этого воспользуйтесь списком сборок выше.

1. Распакуйте ZIP в приложении «Файлы» и откройте `app-github-debug.apk`. Если Android запросит разрешение на установку, дайте его приложению, которым открыли APK.
2. Запустите **Plinth debug**. В настройках включите **Онлайн-источники** и убедитесь, что переключатель **YouTube** включён.
3. В общем поиске введите название песни. В результатах YouTube выберите трек и попробуйте воспроизвести его. Живое воспроизведение на физическом телефоне пока не подтверждено.
